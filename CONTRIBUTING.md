## Use and spread the word
The easiest way to help on the development with ChessBoard-Web.js is to use it! Furthermore, if you like ChessBoard-Web.js, tell all your friends and colleagues about it.

## Give Feedback
User feedback is highly welcome. 

You do not necessarily have to be a programmer to help and make ChessBoard-Web.js even better. There are many ways to contribute.

Translate ChessBoard-Web.js document into a new language or update an existing translation.
Design icons.
Update or extend the wiki user manual.
Write tutorials or create screencasts.
Package ChessBoard-Web.js for your favorite distribution or platform.
TeXstudio is written in Javascript Programmers are welcome to implement new features or fix bugs. Code development takes place on github. Pull-requests, direct patches or changed files are welcome.

It is a good idea to announce your plans on the ChessBoard-Web.js issue list. So everybody knows what's going on around ChessBoard-Web.js and there is no duplicate work. For questions how you can contribute contact one of the developers.
